Known contrast caveat. White on orange measures ~3.7:1 — below WCAG AA for small text, above the 3:1 large-text threshold. Primary CTAs therefore use bold 15–16px and never smaller. Where a long string needs orange, use btn--secondary instead: navy fill with an orange shadow keeps the accent at ~13:1 text contrast.

Typography

Three faces, one job each

Space Grotesk carries headings — a geometric grotesk with odd terminals, so titles read technical rather than as the default Inter every startup page uses. Manrope carries body copy. JetBrains Mono carries the engineering register: eyebrows, pin labels, durations, code.

The signature element

Hard-shadow buttons

One offset solid shadow, and on press the element travels exactly that distance into it. The button physically moves rather than dimming or scaling — that is the whole retro-arcade read, and it is why the UI feels designed rather than assembled. Press one.

TokenValueUsed on
--shadow-hard-sm2px 2px 0 navyLanguage switch, small chips
--shadow-hard3px 3px 0 navyButtons, cards, inputs — the default
--shadow-hard-lg5px 5px 0 navyEmphasis: the school pricing tier, final CTA

The offsets are tokens, not inline values, so every button, card and pricing tier lands on the same distance. One drifting shadow is what makes a system look improvised.

Inputs invert the shadow — inset rather than outset. A field is a hole in the board, not a key sitting on top of it, and the inversion is what stops a form looking clickable.

Texture & motion

Perfboard and the ambient gradient

The dot grid is the site's ground plane — it runs under every section, which is what makes a long page feel like one continuous board instead of a stack of unrelated bands. The gradient appears only on the hero and the registration page.

Perfboard · 16px dense
Animated gradient · 19s / 23s / 27s

Cycle lengths are mutually prime, so the loop never visibly repeats. Motion is transform-only — animating filter or background-position forces a repaint every frame and drops the hero to single-digit FPS on the school laptops this has to run on. Both honour prefers-reduced-motion.
